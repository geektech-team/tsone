# TSone Docs Internationalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build complete Chinese and English MPA documentation with strict route parity, browser-language detection, persisted manual switching, locale-scoped navigation and search, and 28 static pages.

**Architecture:** Keep `DocPage.path` locale-neutral and aggregate separate `zh` and `en` typed-content catalogs behind a locale registry. Shared pure functions own URL conversion and preference resolution; TSone components receive locale context through props, while the build iterates both catalogs and emits localized static routes.

**Tech Stack:** TypeScript strict mode, Bun, `bun:test`, TSone class components and VNodes, Happy DOM, typed style objects, Bun static bundling.

**Spec:** `packages/tsone/docs/superpowers/specs/2026-08-28-docs-i18n-design.md`

## Global Constraints

- Support exactly `zh` and `en` in this phase.
- Chinese keeps existing routes; English uses the `/en/` prefix.
- `DocPage.path` remains a normalized logical path without a locale prefix.
- `/` alone performs automatic detection; explicit content URLs always win.
- Stored manual preference wins over `navigator.languages`; missing browser language defaults to Chinese.
- Both catalogs must contain exactly the same 14 logical routes; no fallback and no mixed-language pages.
- Keep document sources in TypeScript typed content; add no Markdown, handwritten HTML, handwritten JavaScript, JSX, or runtime dependency.
- Preserve `docPages`, `searchEntries`, and `findDocPage` as Chinese-default compatibility exports.
- Keep the runtime dependency-free and preserve unrelated dirty-worktree changes.
- Follow TDD: write each behavior test, observe the expected failure, implement minimally, then rerun focused tests.

```typescript
export interface DocCatalog {
  locale: DocLocale;
  config: DocLocaleConfig;
  pages: DocPage[];
  searchEntries: SearchEntry[];
}

export function createDocCatalog(
  locale: DocLocale,
  sourcePages: DocPage[]
): DocCatalog {
  const pages = validateDocPages(sourcePages);
  if (locale === 'en') {
    const chinesePage = pages.find((page) =>
      /[\u3400-\u9fff]/u.test(docText(page))
    );
    if (chinesePage) {
      throw new Error(
        `Locale en contains Chinese content: ${chinesePage.path}`
      );
    }
  }
  return {
    locale,
    config: DOC_LOCALE_CONFIGS[locale],
    pages,
    searchEntries: createSearchEntries(pages).map((entry) => ({
      ...entry,
      path: localizeDocPath(locale, entry.path),
    })),
  };
}
```

```typescript
function environment(overrides: Partial<LocaleBootstrapEnvironment> = {}): {

    },

describe('docs locale bootstrap', () => {
```
